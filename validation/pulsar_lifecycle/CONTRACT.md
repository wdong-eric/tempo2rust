# Assignment S frozen observational contract

Freeze precedes native execution. `inventory.json` gives all 349 fields, all 95 observation fields, seven nested types, constants/enums/callback signatures, source-write and retention anchors, exact source function bodies and branch sites. Field names are cross-checked against accepted M. `cases.json` fixes bounded histories. No native primary function is patched in the ordinary profile.

Natural pulsars use uninitialized `new pulsar` storage. Export only source-written members, string prefixes through NUL, allocated parameter values/errors/flags/full 100-byte calloc labels, initialized link counts, and real covariance cells. On natural first allocation, every omitted member, parameter link array and prefit buffer is marked unwritten without reading. Embedded-link knownness is independent of prefit-buffer knownness: after caller seeding, repeated allocateMemory/initialiseOne retains the current object's initialized link arrays while replacing its prefit buffers with unwritten storage and resetting link counts. Observation malloc backing is marked unwritten. Header structure padding is never exported. Natural string suffix bytes remain unwritten.

Retention callers seed every scalar and array cell with typed finite distinguishable values, valid enum constants, terminated strings with distinguishable full suffixes, real parameter backing, and registered pointer/callback identities. Counts read by native routines are explicitly bounded afterwards. Every nested field and unused backing is exported. The first seeded owner snapshot includes its initialized ToAextraCovar pointer identity, dimensions, row offsets and two cells. Natural/unwritten or null extra-covariance pointers are never dereferenced for an export. Pointer serialization uses owner tags plus record offsets, never addresses. Callback fixtures are never called and claim no fitter ABI coverage. Empty/null pointer values are explicit fixture values, not inferred defaults.

Whole-state raw records contain little-endian primitive byte values encoded in lossless runs of equal scalar units, plus symbolic pointer arrays. Each record includes unit width and element count. Recursively exported nested structs exclude padding. The decoder validates run lengths and re-encodes every byte stream canonically. Initial, before/after action states and all live alias owners are retained; deltas are derived from complete records without eliminating unchanged fields. Source order is additionally fixed by inventory anchors and overlapping-observation witnesses; no intra-function hook patches source.

The initializer allocates real MAX_FIT=10000 squared covariance. Natural cases read all 100,000,000 element representations and all 10,000 row strides, encode them losslessly, and keep dimensions separate from logical fit counts. Repeated calls save all prior parameter, observation and covariance owners. Old allocations are read only while live, then cleaned by matching native destroy functions after the observation. Shared/interior observation storage is detached before native destruction and its shared owner released once by the harness.

Destruction checks successful completion and exact source order by inspection; they do not claim an instrumented count of every free. Separately allocated early/late constraint strings are used despite nconstraints=0. No freed pointer is subsequently exported or dereferenced. Allocation failure, size overflow, same-pulsar/overlapping strcpy, missing terminators, insufficient capacity, double-free, foreign/interior free and unwritten reads remain unrun. Zero matrix dimensions are separate assert-termination processes. Debug logger and matrix metadata portability remain host/ABI qualifications.

Immutable membership deliberately excludes all active Rust, R/P/Q work and R-authorized parameter-verifier routing files. Other tracked accepted validation evidence is hashed in `protected_hashes.json`. The raw and A2 independent repositories are read-only. This is a reference stage; central retains Rust ownership/API, numeric backend/tolerance, callback ABI and acceptance decisions.

Decision 0042 corrects the implementation of these lifetime rules. The pre-correction 16737d2 bundle is preserved beneath `build/pre0042/`, with an audited manifest. `correction.py` checks the exact allowed projection changes against that bundle; it never refreshes protected membership or changes native source.
