# Binary branch and coordinate inventory

TEMPO2 counterparts: the 14 `*model.C` files, `readParfile.C`, `initialise.C`, `t2fit_stdFitFuncs.C`, `formResiduals.C`. Exact native derivative/update labels and every source `if` condition, with line numbers, are in `source_inventory.json`. The inventory strips comments before extracting conditions; it is not runtime branch instrumentation. `coverage.json` maps actual calls and parameter-presence states to cases. Presence alone does not prove execution of a conditional formula. Every label has runnable evidence; undefined paths have no numerical golden.

All baseline fixtures use twelve unsorted epochs: orbital offsets `0.37, -2, -1.25, -1, -1e-12, 0, 0.125, 0.25, 0.5, 0.75, 1, 2.25`. Negative exact integer orbits retain the source's additional decrement. First original input, not earliest epoch, determines phase reference. Each baseline probes native and wrapper derivatives at five phases (DDK separately isolated), all declared updates with finite, negative and NaN errors, and both residual mean settings. No fit is performed.

## Shared limits

The source functions accept many combinations not represented by these fixtures. Every exact `if` condition stays in the inventory as `inventory_only_not_branch_instrumented`; the named cases above are evidence for specified routes, not an assertion of exhaustive branch coverage. The parameter-presence matrix deliberately includes absent, ignored and unavailable inputs. No analytic derivative, finite-difference repair, generic PB-unit inference or physical parameter validation replaces the source output.

Only equatorial TCB/DE405/IF99 geometry on this macOS arm64 A2 build is exercised by synthetic cases. The separate original DDH ideal test uses its unchanged DE414 fixture. Other time scales, ecliptic transformations, reference-phase modes, selection/tracking, higher companion/subindices, fitting integration, pathological solvers, other architectures and Rust agreement remain open.
