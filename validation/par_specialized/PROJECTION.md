# Caller and observation contract

The 116 released top-level branches plus D029 are reconciled to K's frozen 339 top-level / 559 nested decisions in `inventory.json`. Source text and nested conditions are retained for each selected entry. `projected_fields` gives the exact C declarations and capacities of every fixed field observed. Parameter backing stores for all MAX_PARAMS entries are also included, not just set values. K's earlier evidence is not expanded by inference.

Before each process, the harness assigns every projected field with typed caller values, then invokes unchanged `initialiseOne`. Scalar/array numeric seed is `100 + (field_seed + element_offsets) % 700`; field seeds follow the sorted generated field list, starting at 10 or 1010 by pulsar. Enum seeds are zero. Character arrays are zeroed then, if longer than 30, receive `caller_N_retained_suffix`. Nested numeric arrays include all elements and tails. Natural initialization may overwrite those seeds. Unwritten `ne_sw_ifuncN` and `nWhite_dm` are explicitly caller-zero. After source initialization, jump error arrays receive caller 7+index+psr and 9+index+psr, and jumpScaled receives index modulo 3. Parameter prefit/prefitErr are caller 17+psr / 19+psr, inactive link cells are valid enum values; source initializes counts, values/errors/flags and label allocations. Clock/ephemeris strings receive explicit valid caller text. `initial` records the full resulting state. No raw pulsar padding, pointer values, unwritten local storage or uninitialized allocation tail is read.

Fixed fields and parameter buffers use a lossless initialized-byte representation: `size` and ordered nonzero `[offset, hex]` runs, with all other bytes zero. Bytes follow this measured little-endian ABI; C declarations identify binary32, binary64, binary128 and integer elements. Finite numeric bytes, signed zero and all initialized string tails compare exactly. Initial state plus complete before/after field deltas reconstructs all projected state at each action. Direct dispatch additionally records each token boundary, exact current stream position, EOF/error flags, remaining bytes and changes. Remaining bytes are read using pread at the logical ftell offset, leaving the native FILE state untouched. Native normal exits are observed by an atexit snapshot before native destruction. No libc function or source routine is interposed.

Special constraint allocation lengths are derived by the caller from the exact stream remainder before the real dispatcher runs. Each allocated length is `strlen(remainder)+2`; only the first `strlen(remainder)+1` bytes are read. The last byte is explicitly unknown. For IFUNC_COV the last known byte is newline, not NUL. The returned pointer is never passed to strlen. Source `destroyOne` frees these allocations normally. The mixed reader files use ordinary constraints; special allocations are witnessed through direct dispatch only.

Full and simple reader calls execute source finalization with an explicit PEPOCH, F0 and prefit buffers. Full reader state includes resets, retained FD jumps, links, all selected append counts and both pulsars; global reads the first file for both pulsars. No global ecliptic record is admitted. Direct scratch parameters are explicitly initialized, and no selected fixture reads their unused links. Clock route calls use the real dependency and explicit initialized observations; only initialized route entries are observed. Raw file contents and stdout/stderr are retained before declared build/source-path normalization. Shared raw initial-event lines are stored once by content hash and reconstructed exactly against each raw receipt.

`fixtures.py` defines all bounded histories before execution. Source-undefined paths and diagnostic ABI qualifications are in `inventory.json:undefined_rules`; they are never inferred to be covered from line hits. All other unmeasured semantic paths remain untested-defined. The measured coverage ledger will distinguish compiler outcomes from source decisions. Allocator failure, I/O failure, arbitrary malformed strings and other hosts/backends/locales are outside this corpus.
