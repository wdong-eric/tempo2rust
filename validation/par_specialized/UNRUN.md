Compiler exception/short-circuit outcomes are not independent source paths. No line hit promotes a family to path completeness.

Each source decision with remaining compiler outcomes defaults to **untested-defined**, except the explicit undefined or infeasible cases above. Remaining lexical short-circuit variants, arbitrary token spellings, numerical inputs, non-default process-global logging settings, allocation/I/O failures, host/platform/locale alternatives and complete parser histories are not claimed complete. The corpus is a bounded reference foundation.

TKlog's color-removal pointer arithmetic carries M's conservative host-diagnostic qualification. Cases calling those diagnostics are labeled host observations or normal source exits; they do not supply a portable undefined-behavior oracle. Scientific array/scalar input state remains explicit. This harness does not alter logging, initialization, scanner functions or native source dependencies.
