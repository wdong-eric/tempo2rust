# T comparison contract

The freeze in `rust/verification/pulsar_lifecycle/freeze/` precedes production edits. It validates the 349-field released specification against S's corrected inventory and hashes all six raw source blobs. Git checkout ident expansion is presentation; generators and supplemental native witnesses use the raw blobs. It records all nested fields, types/extents, initializer and copy anchors, twelve full routine bodies, caller sites, S/Q case membership and 8,141 protected local files.

Compare every corrected S case and ordered event, retaining complete record membership/order, typed values, knownness, fixed capacities, suffixes and symbolic owner/offset relationships. Map native layout/sizeof and logger address presentation separately; do not treat those as Rust layout equivalence. The native binary128 significand is 113 bits; finite decoding to the existing 128-significant-bit Rug value is exact. Signed zeros and the accepted nonfinite classes remain distinct. No numeric tolerance is introduced. Full covariance checks read every one of 100 million cells and all 10,000 row offsets.

Q projection includes its `initial_and_helpers` initial packed value and all helper results; unrelated parser semantics remain out of scope. Supplemental native witnesses cover valid generic shifts, clamp boundaries and partially seeded embedded parameter links. Rust-only boundaries are explicit expected behavior, never native goldens.

Observation/matrix/payload pointers map to typed context handles and offsets. Parameter replacement returns the actual prior buffers with retained embedded metadata; retaining this bundle is the one ownership path for old parameter allocations. Source string copying consumes known bytes through the first NUL and retains destination suffixes. Record assignment transfers knownness without semantic reads; forward shared-buffer copies observe each preceding assignment. Independent context Clone duplicates the owner graph; its matrices use immutable shared backing and detach on writes.

All outputs stay under T. Existing oracle files are read-only; ordinary comparison never records them. Execution receipts must bind actual sources, inputs, runners and executable bytes and reject stale evidence.

Diagnostics retain their channel, message order and action boundary. Comparison
projects only source directory spelling and the five native address/layout
messages at TKmatrix.C lines 184/192/194/203/208 to explicit logical descriptions.
Dimensions, allocation sizes, version text, other messages and the final release
message remain exact. Zero-dimension native assertion stderr is classified as
termination; Rust reports its operation-local boundary. No state field is removed
by these presentation projections.

SourcePulsar is a record of context handles, and does not implement public Clone.
Clone the PulsarContext or TimingInput for an independent owner graph. Retired
parameter bundles contain the actual moved allocations; observation/matrix/payload
handles remain live in their original context until explicit release or context
Drop. Context Drop reclaims unreachable source leaks. Diagnostic read access is
separate from mutating lifecycle operations, which refuse terminal reentry.
