## Record and storage contract

Extend the source-correspondence types in `tempo2.rs`; factor a tightly related observation module only if it improves clarity. Use statically typed fields, not a string-keyed runtime map or JSON model. Preserve source binary64 fields, signed 32-bit integer fields, signed 64-bit `pulseN`, Rug128 `longdouble` values, and byte strings. The actual native ABI is measured in the supplemental caller. Rust layout/pointer identity is not the C ABI.

Keep the fixed capacities: filename `MAX_FILELEN+1=501`, telID 100 bytes, 40 flags/jumps, 32 bytes per flag ID/value, 30 TT correction entries and 32 bytes per correction destination, plus every vector/matrix dimension in the header. Source counts remain signed and separate from backing capacities. Do not shrink arrays to active counts, change negative counts to zero, collapse retained tails, or use a boolean for an integer control. `clock_correction` consists of its binary64 correction and complete destination buffer.

Native observation allocation leaves its fields unwritten; the commented initialization loop in `initialise.C` is inactive. The canonical new observation record must therefore start logically unwritten. Use explicit safe initialized/unwritten state for scalars, array cells and bytes. A field's private Rust allocation may be initialized for memory safety, but that must not make it an observed source zero. Distinguish fully unwritten strings, written prefixes through NUL, retained initialized suffixes and holes created by isolated writes. The byte storage needs one clear representation of initializedness, not inferred sentinels or allocator patterns. Avoid a broad generic storage framework; reuse established owned types where their invariants fit.

Reading an unwritten field/byte, a missing terminator needed by that operation, an invalid active index or insufficient backing returns a named operation-local safe boundary. Validate only what the executed branch reads, at that read/write point; do not reject irrelevant unwritten fields before the source would touch them. Preserve completed writes and existing terminal-session behavior on failure. Keep fixed-capacity and initializedness diagnostics distinct. No undefined native access is executed for a golden. Whole-owner Rust cloning copies values, initializedness and all tails into independent storage; it is not a claim to have ported `copyPSR` or every C lifetime operation.

Rug stays at 128 significant bits. Assignment/clone must retain precision, signed zero and declared nonfinite classes. No new arithmetic, token grammar, dependency, backend, rounding mode, numeric ABI or fusion policy is authorized. Source parsing at binary128 versus Rug boundaries remains a later explicit contract.
