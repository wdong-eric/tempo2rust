## Accepted meaning and limits

The evidence preserves the selected binary128 header and measured 113-bit significand, source `%Qg` display versus lossless export, numeric-prefix parsing and exponent quirks, native double/extended boundaries, signed zero/nonfinite classes, bounded integer conversions, sexagesimal carry/wrap expressions, sequential vector alias writes and rotations. Copy observations cover complete initialized source/destination field representations and retained state: copyPSR uses the destination's existing FD-jump count and does not copy parameter arrays; copyParam retains links and backing ownership. Getter links are directional and nonrecursive. Diagnostic key suppression, 50-key history, 30-message storage, counter reset and retained strings remain distinct source behaviors.

Full `ld_*` formatter calls retain their source `va_end`/uninitialized-va_list limitations. TKlog's color removal forms a pointer before its buffer before restoring it; M conservatively classifies affected full diagnostics as host observations. Neither defect was repaired. Later ports and dependency projections must retain these classifications when deciding safe adapters, without treating arbitrary source-undefined values as an oracle.

Unsafe storage accesses, invalid integer conversions, overlapping strcpy, arbitrary/unbounded formats, I/O/allocation failures, TTY behavior, alternate headers/backends, other platforms/locales and full logging coverage remain unverified or explicitly unrun. Independent rotation norm/round-trip diagnostics do not set a Rust tolerance. Full input lifecycle, Rust numeric/format/parameter ownership contracts and the unresolved SVD mode-order gate are not accepted here.
