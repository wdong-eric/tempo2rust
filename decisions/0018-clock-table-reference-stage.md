## Why this stage follows the inventory

The existing Rust tests deliberately reject several source outcomes, so those tests cannot serve as the next port's fidelity oracle.

Central inspected canonical `tabulatedfunction.C`, `clkcorr.C` and active `toa2utc.C` at `fda6ad4a9753ad7dc5d291406f2f310a9161423f`. Tables skip rows with fewer than two successful `sscanf` conversions, retain decreasing samples with a warning, return endpoint proxies outside coverage and can reach defined NaN interpolation at duplicate epochs. Clock routing uses binary32 badness and distances, ordered directed edges, lazy table loading, cached sequences and sequentially shifted binary64 interpolation epochs. `getClockCorrections` can exhaust its fallback ladder and return an empty chain; `getCorrectionTT` then sums to zero. These are source behaviors to measure, not defects to repair.

The active `toa2utc` wrapper also has observable mutation rules beyond routing. It bypasses the clock call when `clockCorr` is 0 or 2, and then still processes SAT jumps. It tests `jumpSAT[l]` inside the observation-jump loop and shifts corrections starting at the newly incremented count. J must preserve those exact indices and writes in bounded fixtures and classify out-of-bounds cases separately.
