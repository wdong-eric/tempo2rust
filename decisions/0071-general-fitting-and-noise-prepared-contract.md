## Public workflow and ownership

Extend AD's general `timing` workflow with an explicit fit request:

```text
tempo2-rust timing --fit --par MODEL.par --tim INPUT.tim --runtime T2runtime
tempo2-rust timing --fit --par P0.par --tim P0.tim --par P1.par --tim P1.tim --runtime T2runtime --covariance MODEL_FILE --norescale -- SOURCE_PREPROCESSING_ARGS
```

Without `--fit`, AD's fixed-parameter command is unchanged. With it, load and preprocess once through AC, then execute the source NITS lifecycle using full BAT/residual recomputation and the built-in fitter. The fit route uses source mean removal (1); reject `--no-mean` combined with `--fit`, rather than silently changing the fit convention. `--covariance` supplies the source covariance selector, including its file, `PSRJ` and inline `MODEL` forms. Preserve the actual resolution context and hash every consumed covariance/INCLUDE input. PAR controls remain authoritative for MODE/WEIGHT, ROBUST, NITS and model-specific noise/constraint settings; avoid duplicate knobs for the same source control. Expose source fit controls not handled by preprocessing, such as forceAlwaysFitForGlitches and acceleration selection, in the fit API and document their CLI mapping before implementing consumers.

Provide a source-mapped direct `t2Fit`/`doFitAll` operation on canonical `PulsarContext` and a full-cycle library operation using the accepted runtime and timing APIs. Callers must be able to inspect rows, columns, design/whitened/constraint matrices, constraint targets, solver outputs and updated canonical state without using the CLI. Freeze concrete signatures and the fit output schema against accepted AD first. The fitted general result must identify every pulsar and cycle, selected row identities, local/global parameter coordinates, supplied/effective controls, fitted increments, physical before/after values and errors, covariance coordinates, rank and raw singular/drop order, chi-square/degrees of freedom, reconstructed noise signals, prefit/postfit timing and provenance. Separate uninitialized/inapplicable state from defined NaN/infinity.

Retain existing bounded `fit_barycentric`, `fit_terrestrial`, `fit` CLI and their schemas as thin input/output adapters over the shared routines. Their explicit input restrictions and established outputs are compatibility contracts. Do not keep a second solver, timing model, parameter store or alternate precision engine. Existing single-pulsar results alone cannot represent a general global fit; the new general fit result uses its own explicit schema.

After release AE owns `rust/` and new `validation/general_fitting/`, as sole Rust writer. Central owns shared decisions and acceptance. Preserve concurrent changes, canonical TEMPO2, A2 and all accepted reference/verification artifacts. Successor generators/comparators use AE-owned staging under policies 0039/0050. Generated JSON/JSONL, binary traces and large outputs remain ignored; commit explicit authored paths with Conventional Commits.

## Source conventions to carry through

1. **Outer iteration.** `tempo2.C:512-568` takes the iteration count from pulsar zero, copies postfit values/errors into prefit storage on later iterations, and runs formBatsAll plus mean-subtracted formResiduals before and after each fit. A linearized residual is not the recomputed nonlinear postfit residual. Do not add automatic convergence or silently fit noise hyperparameters. Built-in TN fitting uses the supplied hyperparameters and source basis/constraint calculation; it is not a Bayesian sampler.
2. **Rows and controls.** `t2Fit_getFitData` snapshots prefitResidual before deletion/START/FINISH filtering, uses SAT for flag 1 and BAT for flag 2 with START_FINISH_DELTA, updates unrestricted START/FINISH, then narrows BBAT-relative days, residual seconds and TOA uncertainties to binary64. A flag value of 2 on START/FINISH selects BAT cuts; it is not an ordinary global fitted parameter. Match selector mutation and observation identity through covariance sorting.
3. **Columns and global layout.** Local fit-info begins with ZERO, then TN jitter epochs, accepted jumps/FDJUMPs and source enumeration/subindices, with globals appended. Global definitions come from pulsar zero. The combined modern matrix puts globals first, followed by each pulsar's locals; update extraction reverses that arrangement. Preserve source indexPsr/indexParam/indexCounter, covariance ownership/copy behavior and sequential updates. Legacy wrappers have their own input layout. Source-zeroed off-pulsar blocks remain zero.
4. **Dispatch and units.** Preserve every label family in t2fit_fillOneParameterFitInfo, multiplicities, jump participation, glitch/exp-dip epoch restrictions and force flag, implicit TN enable/disable mutations and source callback choice. FD/DM/CM, astrometric, binary, glitch, solar, GW and spin parameters do not share one update sign or unit conversion. A standalone callback is not evidence that the default dispatcher supports its label. For example, FDDI routes to explicit notImplemented callbacks and GWECC increments the fit-info count without assigning callbacks; classify those actual paths.
5. **Whitening and constraints.** Without covariance, MODE 0 replaces uncertainties by 1 and weighted modes use the source sigma; the full-covariance path forces MODE 1. Modern covariance code forms lower-triangular L and uses forward substitution, not an explicit inverse. Keep diagonal/full detL formulas, additional covariance, MJD/PSR masking, frequency scaling, zero constraint covariance and the source's conditional Cholesky retry. Preserve constraint order, weights, targets and physical-to-fit-coordinate mappings. Classical constraint rows and TN prior rows are not extra observations when reporting data counts.
6. **Solver.** Binary64 data/matrices become extended SVD inputs at the existing boundary; the source raw mode order, strict cutoff, optional parameter/error/covariance output behavior, augmented dimensions, data-only chi-square and ndata+nconstraints-nparams error scaling remain explicit. Global fitting uses pulsar zero's robust/rescale controls. Defined nonfinite results remain distinct from errors/unwritten outputs. Covariance returned by a robust fit and its reported errors need not obey a generic least-squares rescaling rule.
7. **Robust fitting.** `TKrobust.C` iteratively estimates scale with Huber reweighting and the source median/0.6745, tolerance 1e-5 and count limit, then applies H, B or W for its final solve; unsupported codes fall back to Huber with a diagnostic. Keep the actual source reweighting formulas, in-place residual scaling, first/last covariance distinctions, chi-square formula and writeResiduals save/restore. A comment mentioning Hampel is not an implementation of it.
8. **Timing noise.** Cover red/DM/chromatic/solar-wind, band/group, ECORR/SECORR epochs and shapelet branches, logarithmic frequencies and supplied spectral variants. Preserve source frequency units, data inclusion, field accumulators and squared-error accumulation. Prefit clears designated signal/error arrays; postfit square-roots designated errors and may project TN polynomials or a SWGP mean into deterministic parameters. Preserve TNsubtractPoly's separate basis and postfit controls, the source Legendre/normal-equation algorithm, thresholds and state history unless a demonstrated cache defect is corrected.
9. **Standalone routines and outputs.** Source main/t2Fit does not invoke bootstrap or T2get_covFunc_automatic merely because their library routines exist. Provide direct examples; do not silently insert them into every fit. Bootstrap's partial observation copy, fixed RNG seed, npsr scratch slot and writeTim side effect require real history tests. Preserve optional source fitting output contents/order through explicit owned I/O; do not publish success JSON after a failed fit. Later full output integration remains separate.
