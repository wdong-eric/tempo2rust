## Required coverage

1. **Numeric input and direct display.** Extend `parse_longdouble` evidence across C-locale whitespace, signs/signed zero, decimal/hexadecimal forms, prefixes/trailing characters, D/d spellings, absent digits, nonfinite classes, subnormal/underflow/overflow boundaries and precision-sensitive values. Source FLOAT128 conversion ignores an end pointer; retain its actual behavior. Cover `print_longdouble`'s `%Qg` formatting, precision loss, exponent transitions, signed zero and nonfinite spelling. Distinguish source display from the lossless numeric exporter. Include evidence for alternate-header declarations/macros without changing the chosen production backend.

2. **Formatting entry points.** Inventory and exercise the selected `ld_vsprintf`, `ld_sprintf`, `ld_fprintf` and `ld_printf` responsibilities through fixed, developer-authored, bounded formats with type-matched initialized arguments. Cover literals, `%%`, supported integer/double/binary128/string/character conversions, static flags/width/precision, mixed order, return status, buffer bytes and stdout/file results. Output storage must be sufficient for the actual operation. Do not assume snprintf-style return values, a general printf parser or a 4096-byte caller-capacity guarantee. Inspect unsupported length modifiers, dynamic widths, empty/trailing formats, empty conversions, buffer bounds and the source's `va_end(args)`/uninitialized `oargs`/caller cleanup explicitly. Classify any affected full calls as host/ABI observations, rather than portable defined results, even when stable. Do not repair the formatter, fuzz arbitrary format strings, execute known overreads/overflows or manufacture results after invalid access. Unexecuted branches remain explicit.

3. **Sexagesimal conversion.** Cover `hms_turn`, `dms_turn`, `turn_deg`, `turn_hms` and `turn_dms`: input mutation versus copied input, partial conversions, sign location, one-time degree wrapping, malformed-but-defined scans, positive/negative/signed-zero values, component boundaries, output padding/precision and carry thresholds with adjacent representable inputs. Preserve the actual `isec` expressions and their difference from printed precision; do not replace them with a cleaner coordinate formatter. Bound all source integer conversions and output storage before choosing executable fixtures. Long/incomplete strings that reach invalid source storage are classifications.

4. **Remainders and integer rounding.** Treat both `fortran_mod` overloads separately. Record each source arithmetic type and the actual int quotient conversion; do not substitute an unbounded fmod/Rug remainder oracle. Cover signs of dividend/divisor, exact multiples, signed zero, fractional quotients and representable cases adjacent to the int conversion limits. Cover `fortran_nint` and `fortran_nlong` around signed half ties, zero and the host int/long limits. Derive conversion validity using the expression after its source rounding, not merely the original input. Zero divisors, nonfinite or out-of-range integer conversion are source-based undefined classifications unless an earlier branch avoids the conversion; no arbitrary integer result is a golden.

5. **Vectors and frame rotations.** Exercise `dotproduct`, `vectorsum`, `vectorscale`, `equ2ecl` and `ecl2equ` with basis vectors, cancellation/scale cases, signed zero and defined nonfinite classes. Use valid caller alias/overlap cases for vector operations where C permits them, recording sequential writes; do not assume all outputs are disjoint. Preserve binary64 and binary128 intermediate boundaries, source `LD_PI` and the actual `ECLIPTIC_OBLIQUITY` global. A controlled change to that global is an input, not a changed scientific constant. Independent norm/rotation/round-trip checks are diagnostics separate from exact source observations and must state their error scale.

6. **Copy and linked-parameter state.** Extend K's `copyParam`/`getParameterValue` coverage and cover all `copyPSR` assignments. Use disjoint valid initialized source/destination storage and sufficient capacities; compare copied and retained fields, source unchanged state, strings, observation records, parameter metadata, links and jump arrays. In particular, `copyPSR` does not copy the parameter arrays and iterates FD jumps using the destination's existing `nfdJumps`; preserve those facts rather than writing an ideal deep copy. `copyParam` copies source aSize cells then the size, leaving link arrays/counts alone. Test only safe aliasing; overlapping strcpy, undersized destinations and source-unwritten values have no portable numeric result. Cover all five link formulas, unlinked/default cases, repeated links/source exits and declared nonrecursive behavior, with source type/formula boundaries explicit.

7. **Diagnostic state.** Exercise `displayMsg` directly across types, noWarnings settings, key case/duplication, quiet/debug controls, the 50-key capacity and repeat calls. Keep real process-wide key history and TKlog counters/stored strings. Match source channel/order, DUP1, type distinctions and truncation. Distinguish the 50-key suppression history from TKlog's 30-message storage. Source-location/path rendering can be explicitly normalized, but message content, ordering, counters and truncation cannot be silently discarded. List the exact selected TKlog dependency coverage; this stage does not automatically accept the complete logging/output subsystem.
